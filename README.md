# Elio’s Ocean Investigation

An immersive, illustrated learning experience developed from a creature drawn by Elio at the age of four and his certainty that it lives in the ocean.

Visitors travel through three ocean habitats, investigate how habitat, senses and energy shape marine life, assess Elio’s creature as a biological hypothesis, and design their own ocean animal.

The experience is available in German, English and French.

## Local development

```bash
cd site
npm install
npm run dev
```

## Production build

```bash
cd site
npm run build
```

## Scientific foundations

- [NOAA Fisheries — Shallow Coral Reef Habitat](https://www.fisheries.noaa.gov/national/habitat-conservation/shallow-coral-reef-habitat)
- [NOAA Ocean Exploration — Bioluminescence and Deep-sea Life](https://oceanexplorer.noaa.gov/explorations/02sab/background/edu/media/sab_deep_sea.pdf)
- [NOAA PMEL — Chemosynthesis](https://www.pmel.noaa.gov/eoi/nemo/explorer/concepts/chemosynthesis.html)
- [NOAA Ocean Exploration — Hydrothermal Vent Food Web](https://oceanexplorer.noaa.gov/edu/materials/vent-food-web.pdf)

Aquarium La Rochelle and Robert Hunter’s *Le Monde des Océans* served as loose atmospheric references only. The experience, illustrations and interaction design are original and do not reproduce either source.
